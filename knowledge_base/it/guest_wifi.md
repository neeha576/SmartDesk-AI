# Wi-Fi and Guest Wi-Fi Access

## Employee Wi-Fi
- Network name: **NMTech-Corp**.
- Company laptops connect automatically using a device certificate. No password is needed.
- Personal phones and tablets must use **NMTech-Guest**, not NMTech-Corp.

## Guest Wi-Fi for visitors
- Network name: **NMTech-Guest**.
- Guests need a voucher code sponsored by a NMTech employee.

### How to get a guest voucher
1. Ask the reception desk on the ground floor, **or** go to the IT Service Portal → **Guest Wi-Fi Voucher**.
2. Enter the visitor's name, company and visit dates.
3. The voucher code is emailed to you (the sponsor) instantly. Share it with your guest.

### Voucher limits
- Valid for **24 hours** by default; can be extended up to **5 days** for multi-day visits.
- Up to **3 devices** per voucher.
- Internet access only – guests cannot reach internal systems.
- Speed is limited to 20 Mbps per device.

## Employees' personal devices
You may create a voucher for yourself for personal devices. It renews each day you sponsor it.

## Problems connecting
Forget the network and reconnect, then re-enter the code. If the code is rejected, it may have expired – generate a new one. For anything else, call ext. 2020.
