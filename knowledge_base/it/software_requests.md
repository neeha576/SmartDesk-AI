# Software Installation and License Requests

Employees do not have local administrator rights on company laptops. Software is installed through approved channels only.

## Pre-approved software (install yourself, no approval)
Open **Software Center** (Windows) or **Self Service** (Mac) and click **Install**. The catalog includes Microsoft 365, Zoom, Slack, Visual Studio Code, Python, Git, Docker Desktop, Postman, 7-Zip, Notepad++ and the GlobalProtect VPN client. Installs usually finish within 15 minutes.

## Licensed (paid) software
Examples: Adobe Creative Cloud, JetBrains IDEs, Tableau, Visio, Figma seats.
1. Go to the IT Service Portal → **Request Software**.
2. Choose the product, give a business reason and your cost center.
3. Your manager approves the request in the portal.
4. IT assigns the license and installs it.

**Turnaround:** 3 business days after manager approval.

## Software not in the catalog
Free or open-source tools not in the catalog need an **IT Security review** before installation. Submit through **Request Software → Not in catalog**. Reviews take up to **5 business days**. Browser extensions follow the same process.

## Not allowed
- Pirated or personally licensed software on company devices.
- Remote-access tools (e.g., AnyDesk, TeamViewer) except those provided by IT.
- Personal cloud-sync clients for company data.

## License return
When you no longer need a paid tool, raise a "Return license" request so it can be reassigned. Unused licenses are reclaimed automatically after 90 days of no use.
